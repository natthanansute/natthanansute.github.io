## 👻 การทำงานของ Retro Popup 666 (Easter Egg)

- **หน้าต่างป๊อปอัป (Windows 1 - 5)**: ระบบจะดึงรูปภาพและชื่อโปรเจกต์จาก `projects` ของคุณมาสุ่มแสดงผลโดยตรง ทำให้เชื่อมโยงกับผลงานจริงของคุณได้ทันที (คลิกที่รูปบนป๊อปอัปจะเลื่อนหน้าจอไปยังโปรเจกต์นั้น)
- **ภาพพื้นหลังหลอนใน Step 5**: เมื่อปิดหน้าต่างครบ 5 บาน ระบบจะสุ่มภาพพื้นหลังสดๆ จากคำค้นหาใน `step5SearchQueries` (เช่น Uncanny Valley, Dreamcore, Liminal Space, PS1 Horror) ค้างไว้ 10 วินาทีร่วมกับ Glitch Error

### 🕹️ ปุ่มปริศนาเปิด/ปิด Easter Egg (Mysterious Circle Button)
- **สถานะปกติ (Default - OFF)**: แสดงเป็น **ปุ่มวงกลมจางๆ สีเทา** อยู่ที่มุมล่างขวาของหน้าจอ (`opacity: 0.22` กลมกลืนไปกับพื้นหลัง ดูลึกลับ น่าสงสัย) ทำให้ไม่รบกวนการชม Portfolio ทั้งบนคอมและมือถือ
- **เมื่อกดเปิด (Active - ON)**: ปุ่มจะเปลี่ยนเป็น **สีแดงสด เปล่งแสงชีพจรสีเลือด (Pulsing Red)** และระบบป๊อปอัป 666 จะเริ่มทำงานทันที (สามารถกดปิดได้ทุกเมื่อที่ปุ่มเดิม)

## 🚀 วิธีแก้ไขข้อมูลโปรไฟล์และผลงานโปรเจกต์

เปิดไฟล์ `js/data.js`:
- แก้ไขข้อมูลส่วนตัว: ในก้อน `profile: { ... }` (สามารถกำหนดขนาดโปรไฟล์ได้ เช่น `avatarSize: "150px"`)
- เพิ่มโปรเจกต์ใหม่: คัดลอกและเพิ่มใน `projects: [ ... ]`
- **ใส่หัวข้อย่อย (Bullet Points)**: สามารถใส่ property `bullets: ["ข้อ 1", "ข้อ 2"]` ในแต่ละโปรเจกต์ได้เลย
- **ใส่หลายรูปภาพ (Gallery)**: สามารถเปลี่ยนจาก `image: "..."` เป็น `images: ["รูป1.png", "รูป2.png"]` เพื่อให้แสดงเป็นตาราง Gallery สวยงามได้ทันที
- **ป้ายสถานะแบบกดไม่ได้ (Status / Private Badge)**: สำหรับโปรเจกต์ที่เป็น Private สามารถใส่ Badge โดยไม่ต้องระบุ `url` (หรือใส่ `url: ""` หรือ `url: "#"`) ระบบจะแสดงเป็นป้ายข้อมูลสวยๆ ที่คลิกไม่ได้ให้อัตโนมัติ
- **ระบบ Load More (ดูเพิ่มเติม)**: สามารถปรับจำนวนโปรเจกต์ที่แสดงต่อรอบได้ที่ `projectsPerPage: 3` (หากมีโปรเจกต์มากกว่านั้น จะมีปุ่ม *"ดูโปรเจกต์เพิ่มเติม"* แสดงขึ้นมาอัตโนมัติ)
- **สุ่มลำดับผลงานทุกครั้งที่เข้าเว็บ (Randomize Projects)**: สามารถตั้งค่า `randomizeProjects: true` ใน `js/data.js` เพื่อสุ่มสลับโปรเจกต์แบบไม่ซ้ำกันทุกครั้งที่คนเปิด/รีเฟรชหน้าเว็บ เพื่อโชว์ผลงานหลากหลาย
- **สุ่มสลับตำแหน่งรูปภาพในโปรเจกต์ (Randomize Images)**: สามารถตั้งค่า `randomizeImages: true` ใน `js/data.js` เพื่อสุ่มสลับลำดับรูปภาพในแต่ละโปรเจกต์ (ซ้าย-ขวา) ทุกครั้งที่รีเฟรชเว็บ
- **ระบบคลิกซูมดูรูปภาพ (Google Drive Style)**: คลิกที่รูปผลงานใดก็ได้เพื่อขยายดูขนาดใหญ่เต็มจอ พร้อมปุ่มซูมเข้า/ออก, เลื่อนดูรูปถัดไป และคีย์ลัด Esc
- **ภาพพื้นหลังหลอนใน Step 5 (Dynamic Slop)**: ระบบจะดึงภาพสยองขวัญแบบสดๆ จากคำค้นหาผ่าน `step5SearchQueries` ใน `js/data.js` โดยตรง ไม่จำเป็นต้องใส่ลิงก์รูปภาพทีละภาพอีกต่อไป
